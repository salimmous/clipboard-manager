# ClipboardManager v1.4.0

## ✨ Highlights & New Features
- **Configurable Global Shortcut (`⌘⇧V` default):** Replaces legacy `⌘X` so macOS Cut works everywhere. Switch anytime in Settings (`⌘⇧V`, `⌥⌘V`, `⌃⌥V`, `⌘⇧C`, or legacy `⌘X`).
- **Pause / Incognito Mode:** Pause clipboard capture for 15 minutes, 1 hour, or until resumed directly from the menu bar or popup.
- **macOS Concealed Pasteboard Privacy:** Automatically ignores `org.nspasteboard.ConcealedType`, `TransientType`, and `AutoGeneratedType` markers (protects passwords copied from 1Password, Bitwarden, Apple Passwords, browser extensions, etc.) plus customizable app exclusion list.
- **Launch at Login:** Native macOS `SMAppService` toggle in Settings.
- **Pro Keyboard Workflow:**
  - `⌘1`–`⌘9` instant paste top 9 items
  - `Enter` direct paste / `⇧Enter` paste as plain text
  - `⌘Y` (or `Space` when search is empty) Quick Look preview
  - `⌘P` pin/unpin • `⌘⌫` delete • `Esc` step-back dismiss
  - Auto-focused search with `↑/↓` list navigation while typing
- **Smart Popup & Previews:** Opens near mouse cursor across Spaces & fullscreen apps, auto-closes when clicking outside, renders live hex color swatches (`#RGB`/`#RRGGBB`/`#RRGGBBAA`), shows source app metadata, date & type filters, and Share actions (Slack, Discord, Email, Notes).

## ⚡ Performance & Reliability Fixes
- **Fixed Auto-Updater:** Resolved `URLSession` temp-file race condition and hardened DMG installation with dynamic mount detection, bundle ID verification, and atomic rollback.
- **Async PNG Thumbnails:** Compressed saved images to PNG with `NSCache` thumbnails and automatic orphan file cleanup.
- **Atomic JSON History Storage:** Migrates automatically from `UserDefaults` to `~/Library/Application Support/ClipboardManager/history.json`.
- **Direct Paste & Accessibility:** Checks Accessibility permission with quick grant link, reactivates target app cleanly, and prevents duplicate re-capture on plain-text paste.
- **Pinned Protection & Scheduled Clear:** Clear button protects pinned items by default; Scheduled Auto-Clear & Integrations are fully wired in Settings.

## 📦 Installation / Upgrade
1. Download **`ClipboardManager-1.4.0-Installer.dmg`** below.
2. Open the DMG and drag **ClipboardManager** into **Applications** (replace existing app).
3. Launch **ClipboardManager** — existing history migrates automatically, and future updates (`v1.4.1+`) work with one-click in-app Auto-Update!
