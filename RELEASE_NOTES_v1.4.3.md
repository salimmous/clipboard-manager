# ClipboardManager v1.4.3

## 🎨 Redesigned Native macOS Settings
- **Native Sidebar Layout:** Translucent macOS System Settings-style sidebar with colored icon badges across 6 clean sections (General, Appearance, Privacy & Data, Integrations, Updates, About).
- **Visual Theme Swatch Grid:** Replaces the cramped segmented picker with clickable color-preview cards for all 7 themes.
- **Polished Controls & Status:** Bounded scrollable Ignored Apps list, live Slack/Discord connection status dots, tinted Accessibility permission banner, and unified grouped section cards with full-size transparent titlebar.
