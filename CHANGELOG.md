# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [1.4.1] - 2026-11-22
### Fixed
- Fixed ScrollView jumping back while scrolling (removed `.onHover` → `proxy.scrollTo(..., anchor: .center)` feedback loop; `scrollTo` now triggers only on `↑`/`↓` keyboard navigation with minimal scroll)
- Isolated row hover state inside `ClipboardPopupItemView` and cached `RelativeDateTimeFormatter` for smooth scrolling
- Disabled `isMovableByWindowBackground` on popup window (header `DragAreaView` handles dragging without interfering with list scrolling)

## [1.4.0] - 2026-11-22
### Added
- Configurable global hotkey (default `⌘⇧V` — no longer hijacks macOS `⌘X` Cut) with live re-registration in Settings
- Standard macOS concealed & transient pasteboard protection (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`)
- Pause / Incognito monitoring mode (15 min, 1 hour, or until resumed) with menu bar status icon & popup banner
- Launch at Login (`SMAppService.mainApp`) toggle in Settings
- Fast keyboard navigation: `⌘1`–`⌘9` instant paste, `⇧Enter` plain-text paste, `⌘Y` Quick Look, `⌘P` pin, `⌘⌫` delete, auto-focused search with live `↑/↓` navigation
- Popup opens near mouse cursor across Spaces/fullscreen and auto-dismisses when clicking outside
- Hex color swatch previews (`#RGB`, `#RRGGBB`, `#RRGGBBAA`), source app tracking, and date filter chips
- Wired Share menu (Slack, Discord, Email, Notes), Scheduled Auto-Clear UI, and editable Ignored Apps list
- Automated `XCTest` suite (`ClipboardManagerTests`)

### Changed
- Migrated history persistence from `UserDefaults` to atomic JSON file (`~/Library/Application Support/ClipboardManager/history.json`) with automatic one-time migration
- Compressed image storage from raw `.tiff` to `.png` with async `NSCache` thumbnails and automatic orphan cleanup
- Upgraded URL detection to `NSDataDetector` (supports `.dev`, `.ai`, `.io`, `.ma`, `localhost`, avoids false positives)

### Fixed
- Fixed `AppUpdateManager` download temp-file deletion race and hardened DMG installation script (dynamic volume detection, bundle ID validation, atomic rollback)
- Fixed `AppSettings` first-launch boolean defaults bug and unified settings into `AppSettings.shared`
- Fixed `PasteService` Accessibility permission checks, frontmost app reactivation, and plain-text paste duplicate capture
- Fixed leaked image files on Clear All / eviction / scheduled clear and protected pinned items on Clear
- Fixed CloudKit crash guard on unsigned builds and Swift 6 compiler warnings

## [1.1.12] - 2025-08-01
### Added
- Universal binary support (Intel x86_64 + Apple Silicon arm64)
- Professional DMG installer generation via Makefile
- Automated installation script (`install.sh`)
- Entitlements file for proper permissions (`ClipboardManager.entitlements`)

### Changed
- Build system updated to produce a true universal binary (separate arch builds + lipo)
- `Info.plist` version bump to 1.1.12
- Resource loading updated to use bundle paths (no hardcoded user paths)
- Makefile enhanced with `build-intel`, `build-arm64`, `create-universal`, `app-bundle`, and `create-dmg`

### Fixed
- Removed hardcoded absolute image/icon paths from `Sources/main.swift`
- Addressed DMG unmount reliability during creation

### Notes
- Compatible with macOS 13.0+ (Ventura and later)
- Ready for global distribution; works on any Mac
